# Robotics

Collection of robotics projects: robot simulation, teleoperation, computer vision, and autonomous control using ROS 2 and Python.

## Projects

### 01 — Robotic Arm Teleoperation
A simulated robotic arm controlled through human movements captured by a webcam.

- **ROS 2 Jazzy** for robot communication
- **RViz** for robot visualization
- **URDF** for robot modelling
- **MediaPipe** for human pose estimation
- **Python** for joint-angle calculations and control

### 02 — Humanoid Robotic Hand *(Planned)*
A five-finger robotic hand controlled through real-time hand tracking using MediaPipe.

## Future Development
